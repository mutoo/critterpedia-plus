# Critterpedia Plus

An advanced Critterpedia for Animal Crossing: New Horizons that helps you find new critters easily.

## Screenshots

The time-traveling filters let you inspect critter availability now and later.

![Filters](./screenshots/filters.jpg)

Display critters in a game-like interface to help you finish your collection more easily.

![Insect Grid](./screenshots/insects.jpg)

![Fish Grid](./screenshots/fish.jpg)

More detail than the in-game view.

![Insect Detail](./screenshots/insect-detail.jpg)

![Fish Detail](./screenshots/fish-detail.jpg)

The shadow preview gives you a more intuitive idea of what it looks like.

![Fish Shadow](./screenshots/fish-shadow.jpg)

Visit the live site here:
https://mutoo.github.io/critterpedia-plus/
